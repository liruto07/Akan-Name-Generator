# Akan Name Generator

 Description
The Akan Name Generator is a simple web application that calculates the day of the week a user was born and assigns them an Akan name based on their gender. Akan names come from Ghanaian culture, where children are named according to the day they are born.

---

How It Works
- User enters their birth date (day, month, year)
- User selects their gender
- The app calculates the day of the week they were born
- The app displays the correct Akan name based on gender
